# thats-your-cue

Reserved for shared tooling around [That's your cue](https://github.com/felton/thats-your-cue), a ready-to-shoot Vite starter with React Router, shadcn/ui and Tailwind CSS. There's nothing in it yet.

To start a project, use [create-thats-your-cue](https://www.npmjs.com/package/create-thats-your-cue):

```bash
pnpm create thats-your-cue my-app
```

Docs: [felton.github.io/thats-your-cue](https://felton.github.io/thats-your-cue/)
