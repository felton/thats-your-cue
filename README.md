# That's your cue

A ready-to-shoot Vite starter: React Router, shadcn/ui, Tailwind. Places, everyone.

```bash
pnpm create thats-your-cue my-app
```

**Docs and live demo: [felton.github.io/thats-your-cue](https://felton.github.io/thats-your-cue/)**

| Folder                                                                    | What's in it                                      |
| ------------------------------------------------------------------------- | ------------------------------------------------- |
| [`template/`](template)                                                   | The starter itself. Its README is the full guide. |
| [`packages/create-thats-your-cue/`](packages/create-thats-your-cue)       | The `create` CLI                                  |
| [`packages/thats-your-cue/`](packages/thats-your-cue)                     | Reserved for shared tooling                       |
| [`docs/`](docs)                                                           | The docs site                                     |
